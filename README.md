# 🐼 Curso de Pandas com Python

Curso **completo e gratuito de Pandas com Python**, ministrado por **Téo Me Why**, voltado para quem deseja aprender a manipular, transformar e analisar dados utilizando a biblioteca Pandas.

O Pandas é uma das principais bibliotecas do ecossistema Python para análise de dados, permitindo importar arquivos, explorar informações, realizar transformações e combinar conjuntos de dados de maneira eficiente.

A ideia principal deste curso é fornecer uma base sólida sobre **manipulação e análise de dados com Pandas**, passando pelos principais objetos da biblioteca, importação de arquivos, filtros, transformações, agregações, cruzamento de dados, manipulações adicionais e integração com bancos de dados SQL.

## 🎯 Objetivo

Ao final deste curso, foram desenvolvidos conhecimentos práticos em:

- Manipulação de dados com Python e Pandas.
- Criação e utilização de Series e DataFrames.
- Importação de diferentes formatos de arquivos.
- Exploração, seleção e filtragem de dados.
- Transformação, limpeza e organização de informações.
- Tratamento de valores ausentes e duplicados.
- Agrupamento e agregação de dados.
- Combinação de diferentes conjuntos de dados.
- Manipulação de tabelas e estruturas de dados.
- Integração entre Pandas e bancos de dados SQL.

## 🛠️ Tecnologias utilizadas

- **Python** — linguagem de programação utilizada na análise dos dados.
- **Pandas** — biblioteca para manipulação e análise de dados.
- **Jupyter Notebook** — ambiente para execução de códigos e exploração de dados.
- **SQL** — linguagem utilizada para consultar e manipular dados em bancos relacionais.
